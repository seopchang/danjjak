예문 제거, 카드 모션, 매일 복습 알림, 홈 레이아웃 개편

사용자 요청 4건을 반영했다.

1. 예문 빼기
   Word에서 example 필드를 없앴다. 등록 폼, 수정 폼, 학습 화면,
   목록 표시까지 전부 정리했다.

2. 카드 모션
   답변하면 카드가 옆으로 밀려나고 다음 카드가 반대쪽에서 들어온다.
   아는 단어는 왼쪽, 모르는 단어는 오른쪽으로 나간다.
   뜻은 아래에서 올라오며 나타난다.
   학습 화면과 복습 화면이 같은 모션을 쓰도록 훅으로 분리했다.

3. 매일 복습 알림
   매일 00:00에 로컬 알림을 보낸다. 설정 화면 스위치로 켜고 끈다.
   알림을 누르면 복습 화면이 바로 열린다.
   복습 대상은 덱을 가리지 않고 미암기 우선, 그다음 본 지 오래된 순으로
   최대 50개를 모은다. 단어가 50개보다 적으면 있는 만큼만 넣는다.
   여러 덱이 섞이므로 끝날 때 덱별로 나눠 학습 기록을 남긴다.

4. 레이아웃
   홈이 비어 보인다는 지적을 반영했다. 오늘 복습할 개수를 가장 크게
   보여주고, 전체와 암기완료와 미암기를 타일로 요약했다.
   항상 자리를 차지하던 단어장 추가 입력란은 + 버튼으로 접었다.

검증: tsc 통과, 전 라우트 Metro 번들 통과,
@firebase/auth가 dist/rn으로만 해석되는 것까지 확인했다.
실기기 확인은 아직 못 했다.
